      方法与限制

      比的是什么

      代码固定 a28b202306300924a46a2fdf1ecdf61b568ae627。记录完成于 2026-11-08 15:57:36（新加坡时间）。Jev 用仓库里的 runCart，一单多次请求。Luna 用 /chat/completions，一次整单， json_object，本地 EXTRACTION_SCHEMA 校验后再走店规。这次记录是普通 JSON 加本地校验，服务端 strict JSON schema 不在这次对比里。

      怎么跑的

      5 个样本各 5 次，双方各 25 单计分。AB/BA 交替，并发 1，零重试。每方另有 1 次预热，共 2 单，不计分；预热也正确。计分请求 Jev 80 次、Luna 25 次。含预热本轮 HTTP 110 次，另有 1 次独立探测，合计 111 次。正确性按小票标签的多重集，不计顺序。没有 HTTP 错误、超时、schema 错误或业务错误，所以全部订单和仅正确订单的时延相同。

      计时和思考

      计时是整单墙钟，含完整响应、解析、校验和店规处理，不是首 token。Jev 单次尝试中位 299.8 ms（80 次），整单中位 897.6 ms，因为一单串了多次请求。Luna 每单 1 次请求，尝试中位 1683.5 ms，整单中位 1683.7 ms。请求写了 reasoning_effort: none。全部返回的 usage 都没有 reasoning_tokens 字段。缺字段不是 0，也不能证明网关按 none 关掉了思考。

      用量不能直接比

      Jev 上报 input_tokens 178645、 output_tokens 9555。25 单都没有 total_tokens，缺失不是 0。Luna 上报 prompt_tokens 30355、 completion_tokens 825、 total_tokens 31180。字段不同，这里不比成本。

      不说明什么

      样本名称按记录里的英文说明译成中文，用来指这 5 类；期望小票来自同一份记录。毫秒显示一位小数，由原始值四舍五入。绿色抹茶拿铁的 Luna 最小值是 1309.25 ms，这里写 1309.3。这是小样本、单网关、固定的 5 句混合。路由、网络和 Jev 的串行次数都在时延里。汇总中位不能推出所有任务，也不能推出每一单都更快。原始统计里的 p95 标成探索性，页面不展示。更早的 DeepSeek 记录不是同一时段，不放进这次排名。
