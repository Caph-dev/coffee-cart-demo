    How the slip fills

    一张小票背后的四步行程，也是 Jev Choice 循环本身。

    1. 01 · Ask
      读原话

      把整句口语点单放进 state.request，购物车从空开始。

    2. 02 · Choice
      只挑一件

      从固定菜单里选下一件加入；多杯就多轮，每轮只加一件。

    3. 03 · Check
      核对 last_added

      用 noul 判断刚加入的货是否真被原话覆盖；不够就踢掉。

    4. 04 · Done
      写完收票

      覆盖齐了，或菜单再也装不下剩下的请求，就选 done。
